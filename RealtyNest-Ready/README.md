# RealtyNest - Property Buying & Rental Platform

A beginner-friendly React project with working Home, Properties, Login, Register, Favorites, Property Details, Admin Dashboard, Add/Edit/Delete Properties, Inquiry Management and User Management.

## Run the project

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

- HTML
- CSS

## Important

This is an educational frontend project. Data is stored in browser LocalStorage, so it does not require a backend server or database.


## Demo property catalog

The project now starts with 30 sample Indian property listings across multiple cities, with sale and rental prices shown in Indian Rupees (₹, L, and Cr). Existing browser data is automatically merged with any missing demo listings, so you do not lose properties you added from the Admin page.
